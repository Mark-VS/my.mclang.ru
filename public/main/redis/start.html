Установка и первое знакомство

Установка

Ставим пакет valkey:

# Установка и запуск службы:
sudo pacman -S valkey

# на Debian:
sudo apt install valkey-server

sudo systemctl start valkey

# Проверяем статус:
systemctl status valkey

# Подключиться к серверу:
valkey-cli

# Для совместимости также доступна команда:
redis-cli

Пробуем команды

PING

SET name Mark
GET name

DEL name

Списки:

# Добавим в список mylist два продукта:
LPUSH mylist apple
LPUSH mylist banana

# И теперь выведем содержимое списка:
LRANGE mylist 0 -1
  # элементы добавляются в начало списка

# А теперь добавим элемент в конец списка:
RPUSH mylist orange
# И проверим результат:
LRANGE mylist 0 -1

# Теперь извлечём элемент из списка:
LPOP mylist
