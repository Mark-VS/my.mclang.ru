Файловая структура PeerTube

Пользовательские данные хранятся здесь:

/
├─ var
│  └── www
│      └── peertube
│          ├── storage (пользовательские данные)
│          │   ├── ...
│          │   ├── ... 
│          │   ...
│          ├── peertube-v8.2.4 (распакованный zip-архив)
│          │   ├── config
│          │   │   └── production.yaml – конфигурационный файл
│          │   ├── ...
│          │   ├── ...
│          │   ...
│          ├── peertube-latest (ссылка на peertube-v8.2.4)
│          └── peertube-v8.2.4.zip

storage/plugins/data/peertube-plugin-livechat/prosody/data/peertest.mclang.ru.key – какой-то ключ. У него вот такие права: -r-------- 1 peertube peertube, т.е. его может читать только владелец. И то – только читать.

# Сколько места занимает хранилище:
sudo du -hs /var/www/peertube/storage

# Посмотреть, сколько занимают все папки внутри:
sudo du -h --max-depth=1 /var/www/peertube/storage | sort -hr
