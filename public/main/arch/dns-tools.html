Если не нужна лишняя информация, а нужны только IP-адреса, то добавляем аргумент +short:

dig google.com A @8.8.8.8 +short

  # 64.233.162.113
  # 64.233.162.100
  # 64.233.162.102
  # 64.233.162.138
  # 64.233.162.139
  # 64.233.162.101

Если не указать DNS-сервер, то адрес DNS-сервера будет взят системный (из /etc/resolv.conf).
