happ-cli

Ссылка на Github: github.com/GenkaOk/happ-cli/releases

Нам нужен happ-linux-amd64.tar.gz

Текущая свежая версия: v0.0.4. Скачать можно по ссылке:

curl -LO https://github.com/GenkaOk/happ-cli/releases/download/v0.0.4/happ-linux-amd64.tar.gz

# Распаковываем в домашний каталог:
tar xvzf happ-linux-amd64.tar.gz -C ~/

# Проверяем:
~/happ-linux-amd64/happ --version

# Смотрим доступные команды:
~/happ-linux-amd64/happ --help


# Добавить подписку:
~/happ-linux-amd64/happ sub add 'ССЫЛКА_ПОДПИСКИ' --name myvpn

# Показать подписки:
~/happ-linux-amd64/happ sub list

# Выбрать активную подписку:
~/happ-linux-amd64/happ sub [ИМЯ_ПОДПИСКИ]

# Посмотреть список серверов активной подписки:
~/happ-linux-amd64/happ list

# Обновить подписку:
~/happ-linux-amd64/happ sub update

Подключение:

# Подключаемся к первому в списке серверу в режиме proxy:
~/happ-linux-amd64/happ connect 1 --mode proxy

# то же самое:
~/happ-linux-amd64/happ connect

Порты

Какие порты использует happ-cli?

Праверить, что слушает happ-cli, можно так:


ss -lntp

Судя по выводу, happ-cli запустил сразу два прокси:

  • 127.0.0.1:10808 — SOCKS5;
  • 127.0.0.1:10809 — HTTP-прокси.
