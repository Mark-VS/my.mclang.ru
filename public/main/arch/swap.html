Как создать swap-файл

Для начала создадим пустой файл размером 4 GB:

sudo fallocate -l 4G /swapfile
  • fallocate – создать файл с заранее выделенным дисковым пространством;
  • -l 4G – размер файла 4 GiB;
  • /swapfile – имя и расположение файла

Впринципе то же самое можно сделать с помощью dd:

sudo dd if=/dev/zero of=/swapfile bs=1M count=4096

Создаём swap из пустого файла:

sudo chown 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Проверяем:
free -h
   #                total        used        free      shared  buff/cache   available
   # Mem:           3.8Gi       1.5Gi       792Mi        84Mi       1.9Gi       2.3Gi
   # Swap:          4.0Gi          0B       4.0Gi

mkswap – в начале файла записывается специальная swap-разметка (swap header), чтобы Linux мог распознавать его как swap.

Если нет записи в /etc/fstab, то после перезагрузки нужно будет заново включить подготовленный файл:

sudo swapon /swapfile

# Проверить, включён ли swap-файл:
sudo swapon --show

# Если нужно выключить swap-файл, то:
sudo swapoff /swapfile
