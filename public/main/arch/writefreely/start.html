Первые настройки

lala

  • Подправить ширину контента. Вроде бы я менял две ширины чего-то и margin'ы - чтобы в мобильной версии сократить отступы от краёв;
  • Для мобильной версии уменьшить расстояние между краями экрана и текстом статьи. По умолчанию: 2em. Но 1em смотрится лучше;
  • Убрать для мобильной версии левый margin для меню в левом верхнему углу: я изменил с 1.5em на .5em;
  • Для мобильной версии на страницах Blogs и Drafts убрать расстояние между кнопками Blogs и Drafts, а также сделать отрицательным левый margin у Blogs - кнопки сдвинутся чуть левее, чтобы "New Post" не налазил на них.

1. Отступы от левого и правого края страницы уменьшаем с 2em на 1em, чтобы в мобильной версии они так не бросались в глаза:

#wrapper {
   max-width: 60rem;
}

/* .norm – класс присваивается, если статья написана шрифтом Serif,
   .sans – статья написана шрифтом Sans-serif,
   .wrap – статья написана шрифтом Monospace */
body#collection article.norm,
body#collection article.sans,
body#collection article.wrap {
   max-width: 54rem;
}

/* То же, но для страницы с тегами: */
body#subpage article.norm,
body#subpage article.sans,
body#subpage article.wrap {
   max-width: 54rem;
}

/* То же, но для страницы поста: */
body#post article.norm,
body#post article.sans,
body#post article.wrap {
   max-width: 54rem;
}

2. И ещё вот этот кусок отвечает за какую-то ширину. Возможно, ширину хедера (на странице с тегами):

body#subpage #wrapper h1 {
   max-width: 54rem;
}

3. Отступы от левого и правого края страницы уменьшаем с 2em на 1em, чтобы в мобильной версии они так не бросались в глаза:

article {
   padding-left: 1em;
   padding-right: 1em;
}

4. Для мобильной версии уменьшаем для меню левый отступ с 1.5em на .5em, чтобы он примерно соответствовал отступу контента статьи от левой границы:

@media (max-width: 600px) {
   body#collection nav#manage {
      left: 0.5em;
   }
}

5. Подправляем левый margin и расстояние между Blogs и Drafts для мобильной версии. Эти кнопки необходимо сдвинуть влево, чтобы на них не наезжал "New Post":

@media (max-width: 600px) {
   /* Чуть сдвигаем Blogs влево: */
   #user-nav .tabs a:first-child {
      margin-left: -50px;
   }
   /* Уменьшаем расстояние между Blogs и Drafts с 2em на 1em: */
   header nav#user-nav .tabs > a + a {
      margin-left: 1em;
   }
}
