journalctl

Посмотреть сколько места занимает весь journal:

sudo journalctl --disk-usag
   # Archived and active journals take up 117.8M in the file system.

Запустить журнал в режиме мониторинга:

sudo systemctl -u pixelfed-horizon -f
  • -u – unit. Показывает записи для конкретного юнита;
  • -f – follow. Продолжает следить за журналом и показывать новые строки в реальном времени.

Показать логи за последние пять минут:

# Показать все доступные записи для юнита pixelfed-horizon:
sudo journalctl -u pixelfed-horizon

# Показать все записи для этого юнита за последние 5 минут:
sudo journalctl -u pixelfed-horizon --since "5 minutes ago"

# Показать последние 50 строк:
sudo journalctl -u pixelfed-horizon -n 50

# Показать последние 50 строк, а затем продолжить следить:
sudo journalctl -u pixelfed-horizon -n 50 -f
