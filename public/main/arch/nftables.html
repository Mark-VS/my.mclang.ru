nftables

nftables — современная система фильтрации пакетов Linux, пришедшая на смену старому iptables.

Проверить таблицы (правила):

# показывает правила firewall-а nftables:
sudo nft list ruleset

Когда я выполняю вот такую команду:

ip route show table all

... то я смотрю, таблицы маршрутизации ядра Linux.

  • default via 192.168.1.1 dev enp2s0 означает: Если пакет предназначен неизвестно куда, отправить его через шлюз 192.168.1.1 через интерфейс enp2s0.
  • default via 172.18.0.2 dev tun0 table 2022 означает: В таблице маршрутизации №2022 маршрут по умолчанию ведёт через 172.18.0.2, интерфейс tun0.

А nftables – это фильтрация и обработка пакетов.

В nftables тоже есть понятие table. Но это не таблицы маршрутизации – это таблицы nftables.

nftables может, например, разрешить или заблокировать пакет, перенаправить его, изменить его, сделать NAT, пометить пакет.

Если TCP-порт 22 → разрешить, если TCP-порт 23 → заблокировать. Это уже не маршрутизация.

В nftables таблица – это контейнер для правил firewall'а.

  • ip route – куда отправлять
  • ip rule – какую таблицу маршрутизации использовать
  • nft list ruleset – что делать с пакетами по правилам firewall/NAT/перенаправления
