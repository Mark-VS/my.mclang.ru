Диагностика

# Загрузим HTTP-заголовки страницы:
curl -4 -I https://youtube.com

# То же самое, но через IPv6:
curl -6 -I https://youtube.com

# Более подробный вывод:
curl -4 -I -v https://youtube.com
  • -4 – принудительно использовать IPv4
  • -6 – принудительно использовать IPv6
  • -I – запросить только HTTP-заголовки, без загрузки содержимого страницы

Отправляем запрос на сервер по https, игнорируя сертификат:

curl -k https://akkoma1.mclang.ru/

Пример скачивания с Github'а:

curl -LO https://github.com/GenkaOk/happ-cli/releases/download/v0.0.4/happ-linux-amd64.tar.gz
  • -L – переходить по перенаправлениям Github;
  • -O – сохарнить файл под исходным именем.

Тихий режим

Допустим, я хочу посмотреть заголовки политики безопасности у своего инстанса Pleroma:

curl -sI https://pleroma1.mclang.ru | grep -i content-security-policy

# А можно ещё добавить и -S (--show-error):
curl -sSI https://pleroma1.mclang.ru | grep -i content-security-policy
  • -s (--silent) – подавляет диагностический вывод и индикатор прогресса. Оставляет только полученные данные;
  • -S (--show-error) – показывать сообщения об ошибках, даже если включён -s.
  • -I (--head) – запрашивает только заголовки

Таким образом, мы получим только заголовки(без всякой ненужной шелухи), но при этом если будут ошибки, они тоже отобразятся.

Прокси

Пример скачивания фронтенда Pleroma-FE через прокси:

curl -fL --retry 3 --retry-all-errors \
  --connect-timeout 15 --max-time 180 \
  --proxy http://127.0.0.1:10809 \
  -o akkoma-fe.zip \
  https://akkoma-updates.s3-website.fr-par.scw.cloud/frontend/stable/akkoma-fe.zip
