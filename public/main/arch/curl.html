curl

# Пример скачивания установщика haskell GHCup через http:
curl --proto '=https' --tlsv1.2 -sSf https://get-ghcup.haskell.org | sh

Диагностика

# Загрузим HTTP-заголовки страницы:
curl -4 -I https://youtube.com

# То же самое, но через IPv6:
curl -6 -I https://youtube.com

# Более подробный вывод:
curl -4 -I -v https://youtube.com
  • -4 – принудительно использовать IPv4
  • -6 – принудительно использовать IPv6
  • -I – запросить только HTTP-заголовки, без загрузки содержимого страницы

getent

getent ahosts youtube.com

Здесь getent обращается к системному механизму разрешения имён (NSS), то есть фактически проверяет, какой IP-адрес система сама получит для ютуб.
