Строка приветствия

# Дефолтная строка приветствия:
PS1='[\u@\h \W]\$ '

# Ещё один пример:
PS1='\[\e[1;32m\]\u@\h\[\e[0m\]:\[\e[1;34m\]\w\[\e[0m\]\$ '
  • \u – имя пользователя;
  • \h – имя хоста;
  • \w – текущий рабочий каталог (с полным путём);
  • \W – рабочий каталог (только последний компонент пути);

  • Теперь обсудим вот этот блок:

    \[
...
\]

    то, что находится здесь, не занимает место на экране. Это используется для управляющих последовательностей терминала, например для изменения цвета.

  • \e – означает ESC, т.е. escape-символ.

    [1;32m – это ANSI-код цвета, где 1 – это яркий/жирный режим, а 32 – зелёный цвет.

    \e[1;32m – означает жирный зелёный текст

    \e[0m – означает сбросить форматирование

Теперь расшифруем всю строку:

  • \[\e[1;32m\] – включить жирный зелёный цвет
  • \u@\h – показать mark@hostname
  • \[\e[0m\] – сбросить цвет
  • : – выводим двоеточие
  • \[\e[1;34m\] – включаем жирный синий цвет текста
  • \w – показываем текущий каталог
  • \[\e[0m\] – сбрасываем цвет
  • \$ – показываем $ для обычного пользователя или # – для root.

Управляющие команды

[1;32m – это часть ANSI escape sequence, т.е. команды, которую терминал понимает.

Полная последовательность:

ESC [ 1 ; 32 m
  • [ – это CSI (Control Sequence Introducer). То есть, это начало определённого типа управляющей последовательности. После [ идут параметры: 1;32.
  • m – исторически относится к Select Graphic Rendition (SGR) – управление визуального оформления символов. То есть, это команда, которая отвечает за отображение текста.

Другой пример escape-последовательности:

ESC [ 2 J

Здесь J – это команда очистки экрана, 2 – параметр, который означает очистить ВЕСЬ экран.

То есть, общая идея:

ESC [ <параметры> <команда>

где:

  • [ – начало CSI-последовательности;
  • m – конкретная команда SGR.

В терминал можно вывести текст, окрашенный в жирный зелёный цвет, вот так:

echo -e '\e[1;32mHello\e[0m'


# очистка экрана:
echo -e '\e[2J'

# ... и переместить курсор в левый верхний угол:
echo -e '\e[2J\e[H'

# то же самое, но более явно:
echo -e '\e[2J\e[1;1H'

# убирает пустую строку в самом верху:
printf '\033[2J\033[H'
   # printf не добавляет \n после esc-последовательности
