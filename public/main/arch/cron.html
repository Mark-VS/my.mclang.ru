cron

В Debian пакет называется cron, а в Arch – cronie.

После установки, в фоне должен работать демон cron. В Debian он после установки сам включается, а в Arch придётся включить его самому.

Для управления cron'ом используется утилита crontab.

# Посмотреть список задач для текущего пользователя:
crontab -l

# Посмотреть список задач для root'а:
sudo crontab -l

# Создать новую задачу для root'а:
sudo crontab -e

Строка с задачей должна выглядеть примерно так:

0 4 * * * /usr/local/sbin/backup-peertube.sh

┌──── минута
│ ┌─── час
│ │ ┌── день месяца
│ │ │ ┌─ месяц
│ │ │ │ ┌─ день недели
│ │ │ │ │
0 4 * * *

Разъяснение:

  • 0 – 0-я минута
  • 4 – 4 часа утра
  • * – любой день месяца
  • * – любой месяц
  • * – любой день недели

Ещё примеры:

Каждые 5 минут:
*/5 * * * *

# Каждый час в начале часа:
0 * * * *

# Каждый день в 23:30:
30 23 * * *

# Каждое воскресение в 4:00:
0 4 * * 0

# Каждое первое число месяца в 4:00:
0 4 1 * *

# Только в июле, каждый день в 4:00:
0 4 * 7 *
