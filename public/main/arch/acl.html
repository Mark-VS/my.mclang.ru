ACL

ACL – Access Control List (список контроля доступа)

Установка пакета acl:

# В Arch:
sudo pacman -S acl

# В Debian:
sudo apt install acl

Вместе с пакетом acl установились три утилиты: getfacl, setfacl и chacl.

chacl – устаревшая.

Проверяем права у каталога /var/www/peertube/:

getfacl /var/www/peertube
  # getfacl: Removing leading '/' from absolute path names
  # # file: var/www/peertube
  # # owner: peertube
  # # group: peertube
  # user::rwx
  # group::---
  # other::---

Я как пользователь mark не могу получить доступ к /var/www/peertube/.

Дать доступ

Добавим возможность пользователю mark заходить в папку /var/www/peertube/:

sudo setfacl -m u:mark:--x /var/www/peertube

Проверяем:

getfacl /var/www/peertube
  # getfacl: Removing leading '/' from absolute path names
  # # file: var/www/peertube
  # # owner: peertube
  # # group: peertube
  # user::rwx
  # user:mark:--x
  # group::---
  # mask::--x
  # other::---

Теперь я могу просматривать содержимое каталога от пользователя mark без sudo:

ls /var/www/peertube/storage

Теперь можно с локального компьютера скопировать storage от имени пользователя mark:

rsync -av mark@mclang.ru:/var/www/peertube/storage/ ~/tmp/peertube/

Забрать доступ

Обратно забрать доступ у пользователя mark заходить в папку /var/www/peertube/:

sudo setfacl -x u:mark /var/www/peertube

# полностью вернуть каталог к обычным Linux-правам и отказаться от ACL:
sudo setfacl -b /var/www/peertube
  • -b означает удалить все extended ACL entries.
