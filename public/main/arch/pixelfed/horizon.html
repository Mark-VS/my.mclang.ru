Horizon

Устанавливаем Horizon:

php arisan horizon:install

Дальше просто запускаем Horizon:

php artisan horizon

И Horizon поднимет workers согласно настройкам в: config/horizon.php и будет постоянно обрабатывать очереди.

Создадим unit-файл

sudo touch /etc/systemd/system/pixelfed-horizon.service


[Unit]
Description=PixelFed Laravel Horizon
After=network.target redis-server.service

[Service]
User=mark
Group=mark
WorkingDirectory=/var/www/pixelfed
ExecStart=/usr/bin/php artisan horizon
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

Если папка /var/www/pixelfed/ принадлежит www-data, то тогда лучше поменять поля User и Group на www-data.

После создания unit-файла:

sudo systemctl daemon-reload

# Попробуем запустить сервис:
sudo systemctl start pixelfed-horizon

# Если всё запускается нормально, то можно включить автозапуск:
sudo systemctl enable pixelfed-horizon

  # типа пусть php8.4-fpm и nginx живут своей независимой жизнью

[Service]

User=mark
Group=mark
Restart=on-failure

[Install]
WantedBy=multi-user.target
