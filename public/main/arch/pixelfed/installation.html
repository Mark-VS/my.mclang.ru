Установка PixelFed

План

  • Подготовить PostgreSQL
  • Установить Redis
  • PHP
  • Composer
  • PHP-FPM (FastCGI Process Manager)
  • Скачиваем PixelFed

Ставим PHP:

sudo pacman -S php

# Или:
sudo apt install php

# проверяем:
php -v

Пробуем запустить скрипт. Сначал напишем его в файле test.php:

<?php
echo "Привет, это Какашка.\n";

А затем запустим:

php test.php

Ставим Composer:

sudo pacman -S composer

# или:
sudo apt install composer

У PixelFed примерно такая схема:

Браузер
     │
     ▼
Nginx
     │
     ▼
PHP-FPM
     │
     ▼
PixelFed (PHP-код)

То есть сам PixelFed не слушает HTTP-порт.

Он просто лежит в виде файлов, а PHP-FPM выполняет эти файлы по просьбе Nning.

PHP-FPM

php-fpm необходим для связки Nginx c php. Теоретически, Nginx может просить выполнить код и php, но это очень медленно работает. php-fpm очень хорошо оптимизирует эту работу и грамотно разделяет на потоки процесс выполнения.

sudo pacman -S php-fpm

# Проверяем:
php-fpm -v
   # в Debian бинарник php-fmp не запускается –
   # есть только сервис php8.4-fpm

# Запускаем сервис:
sudo systemctl enable --now php-fpm
# в Debian сервис уже активирован после установки. Можно преверить:
systemctl is-active php8.4-fpm

# Посмотреть какой сокет создал php-fpm:
ls -l /run/php-fpm/
   # total 0
   # srw-rw---- 1 http http 0 Aug  4 21:57 php-fpm.sock

# В Debian:
ls -l /run/php/
    # total 4
    # lrwxrwxrwx 1 root     root     30 Aug  8 14:08 php-fpm.sock -> /etc/alternatives/php-fpm.sock
    # -rw-r--r-- 1 root     root      5 Aug  8 14:08 php8.4-fpm.pid
    # srw-rw---- 1 www-data www-data  0 Aug  8 14:08 php8.4-fpm.sock

# Или можно так:
find /run -name "*.sock" | grep php

php-fpm.sock – это не файл. Первая буква s означает Unix socket.

Ограничение размера загружаемых файлов

По умолчанию php-fpm не будет разрешать нам загружать файлы больше 2 MB.

Чтобы это дело исправить, нам нужно зайти в файл настроек php-fpm: /etc/php/8.4/fpm/php.ini

Настройки по умолчанию:

post_max_size = 8M
upload_max_filesize = 2M

Заменим их на что-то более подходящее:

post_max_size = 25M
upload_max_filesize = 20M

А затем перезагружаем php-fpm:

sudo systemctl restart php8.4-fpm

Теперь создадим файл index.php:

// ~/projects/php/index.php

<?php

phpinfo();

Настраиваем Nginx:

# ...
server {
    listen 8081;
    server_name localhost;

    ## Важно!! Не запихивать root и index внутрь "location /"
    ## потому что внутри каждого нового блока root по умолчанию: /var/www/html;
    root /home/mark/projects/php;
    index index.php;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include fastcgi.conf;
        fastcgi_pass unix:/run/php-fpm/php-fpm.sock;
    }
}
  • fastcgi_pass unix:/run/php-fpm/php-fpm.sock; – это сокет.

Перезагружаем Nginx:

# Проверяем конфигурацию:
sudo nginx -t

# Если всё хорошо, перезагружаем Nginx:
sudo systemctl restart nginx

Теперь вводим в строку браузера: http://localhost:8081 и должна открыться страница phpinfo().

Всё хорошо. PHP-FPM работает.

Можно поэкспериментировать с php-кодом. Изменим index.php на:

<?php

echo "
Привет
";
echo "
Сегодня: " . date('Y-m-d H:i:s') . "
";

Время будет меняться при каждом обновлении странички. Т.е. PHP действительно выполняется на сервере.

Как подключиться из PHP к PostgreSQL

Для начала нам необходим драйвер PostgreSQL для PHP.

# Проверяем, установлен ли драйвер:
php -m | grep pg

# Если его нет, то устанавливаем:
sudo pacman -S php-pgsql

# или:
sudo apt install php-pgsql

На Arch пакет php-pgsql не создаёт автоматически файл /etc/php/conf.d/pgsql.ini. Расширение нужно включить самостоятельно. Создадим этот файл:

extension=pdo_pgsql
extension=pgsql

И теперь опять проверяем:

php -m | grep pg
   # pdo_pgsql
   # pgsql

Перезагружаем php-fpm:

sudo systemctl restart php-fpm

И теперь можно открывать в браузере страничку http://localhost:8081/.

Обязательные расширения

Проверим, каких обязательных расширений нам не хватает:

php -m | grep -E 'bcmath|ctype|curl|intl|mbstring|openssl'
  # ctype
  # intl
  # mbstring
  # openssl

У меня (на Debian) не хватает двух обязательных расширений:

  • bcmath
  • curl

Установим их (нам нужна не curl, а php8.4-curl):

sudo apt install php8.4-curl php8.4-bcmath
