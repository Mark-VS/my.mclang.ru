  # = true

config_cache('federation.activitypub.enabled')
  # = "0"

У нас выключен ConfigCache. Нужно включить ActivityPub через административную настройку PixelFed, чтобы в его ConfigCache записалось: federation.activitypub.enabled = 1.

В Settgins – Overview есть checkbox ActivityPub. Нужно его включить. И затем нажимает кнопку "Save".
