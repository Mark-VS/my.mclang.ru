ss

ss – замена старому netstat

ss -t src :443

# показывает TCP-соединения, которые ...
# ... находятся в состоянии SYN-RECV:
ss -ant state syn-recv

# считает кол-во строк вывода предыдущей команды:
watch -n1 'ss -ant state syn-recv | wc -l'

# кто слушает порт 443:
sudo ss -lntp | grep 443:

# посмотреть очередь ожидания:
ss -lnt

# кто владелец сети:
whois 91.221.176.1

Какие бывают типы соединений:

  • LISTEN
  • ESTAB
  • UNCONN – обычно относится к UDP-сокетам, потому что UDP не устанавливает соединение так, как TCP.
  • SYN-SENT
  • SYN-RECV
  • FIN-WAIT-1
  • FIN-WAIT-2
  • TIME-WAIT
  • CLOSE-WAIT
  • LAST-ACK
  • CLOSING
  • CLOSED

# Показать все TCP-сокеты (кроме слушающих):
ss -t

# Показать все сокеты:
ss -a

# Unix domain sockets:
ss -x

# RAW sockets:
ss -w

# Показать все TCP-сокеты:
ss -ta

# Показать только слушающие TCP-сокеты:
ss -tl

# Добавить колонку с процессами, которые владеют этими сокетами:
ss -tlp

# Показать только установленные (ESTAB) TCP-соединения:
ss -t state established

Unix domain socket — это способ, которым процессы на одном и том же компьютере общаются друг с другом. Часто такой сокет выглядит в файловой системе как файл (например, /run/user/1000/something.sock). Это тоже вполне себе обычные сокеты, просто вместо IP-адреса и TCP/UDP они используют механизм IPC внутри одного компьютера.

Покажи все TCP-соединения и TCP-сокеты, где на моей стороне используется порт 443!

ss -t src :443

  • ss – показать сокеты/соединения
  • -t – только TCP
  • src :443 – показать записи, у которых локальный (source) порт равен 443
  • -s – summary (сводка) – не показывает сами сокеты, а выводит статистику по ним
  • -l – только слушающие порты
  • -p – процессы, владеющие сокетами
  • -n – не преобразовывать номера портов в имена (443 вместо https)

Проверить, слушает ли кто-нибудь порт 10808, можно вот так:

ss -ltpn | grep 10808

Проверить сразу несколько портов:

ss -ltpn | grep -E "20170|20171|10808"

Проверим, установлены ли соединения на портах 20170 и 10808:

nc -zv 127.0.0.1 20170
  # nc: connect to 127.0.0.1 port 20170 (tcp) failed: Connection refused

nc -zv 127.0.0.1 10808
  # Connection to 127.0.0.1 10808 port [tcp/*] succeeded!
