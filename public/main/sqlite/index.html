SQLite

Прежде всего, нужно установить sqlite3:

sudo apt update
sudo apt install sqlite3

Создать новую базу данных:

# от имени текущего пользователя:
sqlite3 mydb.db

# от имени пользователя writefreely:
sudo -u writefreely sqlite3 mydb.db

Открыть уже имеющуюся базу данных:

# от имени текущего пользователя:
sqlite3 dbname.db

# но лучше запускать базу данных от имени пользователя, которому принадлежит файл:
sudo -u writefreely sqlite3 writefreely.db

# и мы сразу же попадаем в интерактивную консоль.

Выйти из интерактивной консоли:

.quit

-- Или просто:
Ctrl+D

Бэкап

Бэкап можно делать, просто скопировала файл базы данных. Предварительно желательно остановить WriteFreely (или другие сервисы, которые используют эту базу данных), а потом выполнить копирование.

Но у SQLite есть и встроенный механизм для создания бэкапа, который можно использовать, не останавилвая сервисы:

sudo -u writefreely sqlite3 /opt/writefreely/writefreely/writefreely.db \
   ".backup '/opt/writefreely/writefreely/writefreely-2026-10-08.db'"

А ещё лучше автоматически формировать дату и время при бэкапе:

sudo -u writefreely sqlite3 /opt/writefreely/writefreely/writefreely.db \
  ".backup '/opt/writefreely/writefreely/writefreely-backup-$(date +%Y-%m-%d_%H-%M-%S).db'"

Восстановление из бэкапа

Перед восстановлением проверяем бэкап на целостность:

sudo -u writefreely sqlite3 /opt/writefreely/writefreely/writefreely-2026-10-08_17-35-22.db \
   "PRAGMA integrity_check;"

# и восстанавливаем базу данных:
sudo -u writefreely sqlite3 /opt/writefreely/writefreely/writefreely.db \
   ".restore '/opt/writefreely/writefreely/backup-writefreely-2026-10-08_20-46-22.db'"

Во время восстановления базы данных из бэкапа лучше остановить WriteFreely (или другой сервис) во избежание недоразумений.
