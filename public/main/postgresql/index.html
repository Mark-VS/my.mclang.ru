PostgresQL

  • postgresql – пакет в репозитории Arch
  • postgresql-libs (ставится автоматически как зависимость) – этот пакет нужен программам, которые умеют подключаться к PostgresQL (типа GotoSocial, PeerTube, Synapse, psql и т.д.)

psql – это официальный консольный клиент PostgreSQL.

Основные понятия:

  • сервер: postgresql.service
  • кластер: /var/lib/postgres/data
  • база данных: postgres, template0, template1, testdb
  • роль (пользователь / группа): postgres
  • клиент: psql

Роли

Роли бывают двух видов:

  • Роль без LOGIN:

    -- Пример создания роли без LOGIN:
CREATE ROLE developers;

  • Роль с LOGIN: 

    -- Пример создания роли с LOGIN:
CREATE ROLE mark LOGIN PASSWORD 'мой_сеКрЕТный_парОлЬ';

Некоторые роли имеют атрибут LOGIN, а некоторые – нет. Те, что не имеют – это по сути группы, а те, что имеют – это пользователи.

Т.е., пользователь – это роль, которой разрешён вход, а группа – это роль, которой запрещён вход.

Установка PostgreSQL

Устанавливаем PostgreSQL:

sudo pacman -S postgresql


# Проверяем, запущен ли daemon.
# В нашем случае он не запущен.

sudo systemctl status postgresql
  # ○ postgresql.service - PostgreSQL database server
  #     Loaded: loaded (/usr/lib/systemd/system/postgresql.service; disabled; preset: disabled)
  #     Active: inactive (dead)
  #       Docs: man:postgres(1)

Сначала проверим, был ли уже инициирован каталог с данными:

sudo ls -la /var/lib/postgres
  # total 12
  # drwx------  3 postgres postgres 4096 Aug  2 14:17 .
  # drwxr-xr-x 22 root     root     4096 Aug  2 14:17 ..
  # drwx------  2 postgres postgres 4096 Aug  2 14:17 data

sudo ls -la /var/lib/postgres/data
  # total 8
  # drwx------ 2 postgres postgres 4096 Aug  2 14:17 .
  # drwx------ 3 postgres postgres 4096 Aug  2 14:17 ..

# Каталог data уже есть, но он пустой. Значит, он не иницилизирован. Инициализацию нужно выполнить вручную.

Инициализируем вручную каталог /var/lib/postgres/data (создаём кластер):

sudo -iu postgres

initdb -D /var/lib/postgres/data

# Если хочется явно задать локаль и кодировку, можно использовать:
initdb --locale=C.UTF-8 --encoding=UTF8 -D /var/lib/postgres/data

# После сообщения об успешном завершении можно выйти:
exit
  • -i – это сокращение от initial login, оно говорит sudo: "Войди так, как будто пользователь postgres только что вошёл в систему."
  • -u – user, т.е. команда выполняется от имени пользователя postgres.

Теперь запускаем daemon:

sudo systemctl start postgresql

Теперь у нас запущен сервер PostgreSQL.

Подключение к серверу

Теперь подключаемся к серверу:

sudo -iu postgres

# а затем:
psql
  # psql (18.4)
  # Type "help" for help.
  #
  # postgres=#

на postgres=# — это приглашение psql.

Базовые команды

Команды:

-- Посмотреть версию:
SELECT version();

-- Посмотреть имя текущего пользователя:
SELECT current_user;

-- Посмотреть имя текущей базы данных:
SELECT current_database();

Несколько специальных команд:

-- Все базы данных:
\l

-- Или (более современный вариант):
\l+

-- Все пользователи (роли):
\du

-- Все команды psql:
\?

-- Справка по SQL:
\h
-- Справка по команде "CREATE TABLE":
\h CREATE TABLE

-- Выйти из psql:
\q

В полевых условиях

Создадим собственную базу данных:

CREATE DATABASE testdb;

-- Проверим:
\l

-- Подключаемся к ней:
\c testdb

Создадим новую роль mark с атрибутом LOGIN (пользователя):

CREATE ROLE mark LOGIN PASSWORD 'п1а2р3о4л5ь';

-- И проверим роли:
\du

Создадим базу данных, которой будет владеть mark:

CREATE DATABASE markdb OWNER mark;

-- Проверим:
\l

А теперь подключимся к нашей новой базе данных как новый пользователь:

-- Для начала выходим из psql:
\q

# ... и подключаемся как mark:
psql -U mark -d markdb
