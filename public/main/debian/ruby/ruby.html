На данный момент последняя версия: 4.0.10.

sudo apt install build-essential libssl-dev libyaml-dev \
  libreadline-dev zlib1g-dev libffi-dev libgdbm-dev \
  libncurses-dev autoconf bison

Проверяем, установлены ли пакеты.

Debian:

apt list --installed build-essential libssl-dev libyaml-dev \
  libreadline-dev zlib1g-dev libffi-dev libgdbm-dev \
  libncurses-dev autoconf bison
  • build-essential – компилятор и инструменты сборки;
  • libssl-dev – OpenSSL
  • libyaml-dev – YAML
  • libreadline-dev – Readline
  • zlib1g-dev – Zlib
  • libffi-dev – FFI
  • libgdbm-dev – GDBM
  • libncurses-dev – Ncurses
  • autoconf – GNU Autoconf – инструмент для автоматической подготовки сценария конфигурации программы.
  • bison – GNU Bison – генератор синтаксических анализаторов (parser generator).

В Arch'е вместо build-essential нужен base-devel. При этом autoconf и bison находится внутри base-devel. Их не нужно ставить отдельно. Вроде бы как. Со слов ГПТ.

Arch (проверяем те же библиотеки, кроме autoconf и bison):

pacman -Q base-devel openssl libyaml \
  readline zlib libffi gdbm ncurses

Скачиваем исходники:

curl -# -O https://cache.ruby-lang.org/pub/ruby/4.0/ruby-4.0.10.tar.gz

# Распаковываем архив:
tar xzvf ruby-4.0.10.tar.gz

# И переходим в созданную папку:
cd ruby-4.0.10


# Подготовим исходники к сборке и создадим Makefile ...
# ... и укажем путь для дальнейшей установки программы:
./configure --prefix=/usr/local

# Запускаем компиляцию:
make -j$(nproc)
   # ждём около минуты (на моём ПК)

# Проверим собранный интерпретатор:
./ruby --version
   # ruby 4.0.10 (2026-11-19 revision a704b7cd95) +PRISM [x86_64-linux]

# Тесты:
make test

# И установка:
sudo make install


# После установки проверим:
ruby --version
  # ruby 4.0.10 (2026-11-19 revision a704b7cd95) +PRISM [x86_64-linux]

command -v ruby
  # /usr/local/bin/ruby

ruby -ropenssl -e 'puts OpenSSL::OPENSSL_VERSION'
 # OpenSSL 4.1.0 23 Oct 2026

Удаление

Если сохранилась папка с Makefile, то можно запустить из неё:

sudo make uninstall

Почему-то удаляется всё, кроме файла /usr/local/lib/ruby/gems/4.0.0/plugins/rdoc_plugin.rb.

А если Makefile не сохранился, то удаляем всё вручную:

# Бинарники:
sudo rm /usr/local/bin/{bundle,bundler,erb,gem,\
  irb,minitest,racc,rake,rbs,rdbg,rdoc,ri,\
  ruby,syntax_suggest,test-unit,typeprof}

# Библиотеки:
sudo rm /usr/local/lib/libruby-static.a
sudo rm /usr/local/lib/pkgconfig/ruby-4.0.pc
sudo rm -rf /usr/local/lib/ruby

# Заголовочные файлы:
sudo rm -rf /usr/local/include/ruby-4.0.0

# Документация:
sudo rm -rf /usr/local/share/doc/ruby
sudo rm -rf /usr/local/share/ri/4.0.0
sudo rm /usr/local/share/man/man1/{ruby.1.gz,erb.1.gz}
