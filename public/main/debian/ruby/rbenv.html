rbenv

Страничка на Github: github.com/rbenv/rbenv

Страничка ruby-build: github.com/rbenv/ruby-build

  • rbenv – управляет версиями Ruby;
  • ruby-build – отвечает за скачивание исходников и компиляцию конкретных версий;
  • gem – менеджер пакетов (библиотек) Ruby;
  • Bundler – это менеджер зависимостей Ruby. Он не является частью rbenv, хотя обычно используется вместе с ним. Это инструмент, который устанавливает и контролирует конкретный набор библиотек, необходимых приложению.

Допустим, у меня rbenv установлен в пользовательскую папку юзера mastodon. Тогда его нужно искать в /home/mastodon/.rbenv/.

ls -lh /home/mastodon/.rbenv/bin/rbenv
  # lrwxrwxrwx 1 mastodon mastodon 16 Nov  4 18:57 /home/mastodon/.rbenv/bin/rbenv -> ../libexec/rbenv

Посмотреть, какие версии Ruby у меня установлены:

sudo -u mastodon /home/mastodon/.rbenv/bin/rbenv versions
  # * 4.0.9 (set by /home/mastodon/.rbenv/version)

Проверить активную версию:

sudo -u mastodon /home/mastodon/.rbenv/bin/rbenv exec ruby -v
  # ruby 4.0.9 (2026-10-23 revision 3e93b23afc) +PRISM [x86_64-linux]

Посмотреть версию, которую проект Mastodon запрашивает через rbenv:

cat /home/mastodon/live/.ruby-version
  # 4.0.9

Можно посмотреть, какие версии Ruby физически установлены:

ls -l /home/mastodon/.rbenv/versions/
  # total 4
  # drwxr-xr-x 6 mastodon mastodon 4096 Nov  4 19:28 4.0.9

Установка

По сути, просто копируем с Github'а и выполняем инициализацию:

git clone https://github.com/rbenv/rbenv.git ~/.rbenv

#  Добавим rbenv в PATH и подключим его к Bash:
echo 'export PATH="$HOME/.rbenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(rbenv init -)"' >> ~/.bashrc

source ~/.bashrc

rbenv init - – эта команда подготавливает окружение Bash для работы с rbenv.

Она генерирует скрипт в виде текста, который выполняется командой eval как код и результат записывается в ~/.bashrc с помощью echo.

Но предварительно, чтобы rbenv init - сработал, нам нужно добавить путь $HOME/.rbenv/bin в переменную PATH.

А далее ставим ruby-build, то есть, копируем его с Github'а в папку с плагинами в .rbenv/:

git clone https://github.com/rbenv/ruby-build.git "$(rbenv root)/plugins/ruby-build"

Проверяем:

rbenv --version
  # rbenv 1.3.2-25-g07e9b1e

# Все установленные версии:
rbenv versions
  # * 4.0.9 (set by /home/mastodon/.rbenv/version)

# Проверить выбранную версию:
rbenv version
  # 4.0.9 (set by /home/mastodon/.rbenv/version)

# Вот так можно указать, какую версию Ruby использовать по умолчанию:
rbenv global 4.0.9

rbenv install --list | grep 4.0.9
  # 4.0.9

# Посмотреть путь к исполняемому файлу:
 which ruby
  # /home/mastodon/.rbenv/shims/ruby

Запускаем компиляцию Ruby, находять под пользователем mastodon:

RUBY_CONFIGURE_OPTS=--with-jemalloc rbenv install 4.0.9


# Ещё раз посмотрим версию, которую использует Ruby по умолчанию:
rbenv global 4.0.9

rbenv install --list | grep 4.0.9
  # 4.0.9

# Посмотреть путь к исполняемому файлу:
 which ruby
  # /home/mastodon/.rbenv/shims/ruby

rbenv versions
* 4.0.9 (set by /home/mastodon/.rbenv/version)
  4.0.10

# Временно переключимся на 4.0.10 в текущем сеансе терминала:
rbenv shell 4.0.10
# Вернёмся обратно:
rbenv shell 4.0.9

ruby -v
  # ruby 4.0.10 (2026-11-19 revision a704b7cd95) +PRISM [x86_64-linux]

Проверим Ruby (от пользователя mastodon):

ruby -v
  # ruby 4.0.9 (2026-10-23 revision 3e93b23afc) +PRISM [x86_64-linux]

gem -v
  # 4.0.20

# Проверим версию Bundler:
bundle -v
  # 4.0.20

Обновление

Вышла новая версия Ruby: 4.0.10. А у меня установлена 4.0.9.

Но rbenv install --list не отображает новую версию, потому что у меня не обновлён ruby-build. А именно он должен ...

Обновим ruby-build:

git -C /home/mastodon/.rbenv/plugins/ruby-build pull

А теперь опять выполним команду rbenv install --list и новая версия v4.0.10 будет доступна.

Вывести аргументы конфигурации, с которыми был собран Ruby:

rbenv exec ruby -rrbconfig -e 'puts RbConfig::CONFIG["configure_args"]'
  # '--prefix=/home/mastodon/.rbenv/versions/4.0.9' '--enable-shared' '--with-ext=openssl,psych,+' '--with-jemalloc'

То есть, вот параметры сборки Ruby 4.0.9:

--enable-shared
--with-ext=openssl,psych,+
--with-jemalloc
  • --enable-shared – собирает Ruby как разделяемую библиотеку libruby.so;
  • --with-ext=openssl,psych,+ – управляет сборкой расширений Ruby. В частности, гарантирует сборку OpenSSL и Psych;
  • --with-jemalloc – использует jemalloc вместо стандартного системного аллокатора памяти.

Установим Ruby 4.0.10 с аналогичными параметрами:

RUBY_CONFIGURE_OPTS="--enable-shared --with-ext=openssl,psych,+ --with-jemalloc" \
  /home/mastodon/.rbenv/bin/rbenv install 4.0.10

Если мы предварительно не запустили shell от имени mastodon, то тогда так:

sudo -u mastodon -H env \
  RUBY_CONFIGURE_OPTS="--enable-shared --with-ext=openssl,psych,+ --with-jemalloc" \
  /home/mastodon/.rbenv/bin/rbenv install 4.0.10

Проверим теперь доступные версии Ruby:

rbenv versions
* 4.0.9 (set by /home/mastodon/.rbenv/version)
  4.0.10

И переключимся на новую версию 4.0.10:

rbenv global 4.0.10

# Проверяем:
rbenv versions
  4.0.9
* 4.0.10 (set by /home/mastodon/.rbenv/version)
