Посмотреть, на каком именно коммите сейчас находится мой репозиторий Mastodon:

# Посмотрим тег текущей версии:
sudo -u mastodon git -C /home/mastodon/live describe --tags --exact-match
  # v4.7.5

# Идентификатор и описание текущего коммита:
sudo -u mastodon git -C /home/mastodon/live log -1 --oneline
  # 24cd1c875a (HEAD, tag: v4.7.5, origin/stable-4.7) Bump version to v4.7.5

Допустим, я хочу проверить наличие новых версий в репозитории через git.

Для этого скачаем информацию о новых тегах из удалённого репозитория:

sudo -u mastodon git -C /home/mastodon/live fetch --tags

И теперь просмотрим версии в порядке убывания:

sudo -u mastodon git -C /home/mastodon/live tag --sort=-version:refname | head -10
  # v5.0.0-beta.2
  # v5.0.0-beta.1
  # v4.7.6
  # v4.7.5
  # v4.7.4
  # v4.7.3
  # v4.7.2
  # v4.7.1
  # v4.7.0-rc.1
  # v4.7.0-beta.1

Здесь видно, что текущая стабильная версия – 4.7.6.
